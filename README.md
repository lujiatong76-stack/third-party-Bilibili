# 第三方哔哩哔哩客户端 · PC 版

Windows / Linux 通用的 B 站第三方客户端。Python 3 编写，**只用标准库**，不需要 pip 安装任何东西。

- 版本：v1.9.2
- 平台：Windows 10/11、Linux（桌面）
- 依赖：Python 3.8+，以及系统里任意一个 Chromium 系浏览器（Edge / Chrome / Chromium / Brave，程序会自动找）

---

## 一、怎么运行

Windows 双击 `run.bat`；Linux 执行 `./run.sh`。

启动后会弹出一个独立的应用窗口（无地址栏、无标签页）。侧栏底部有「扫码登录」与「退出程序」：
点「退出程序」会先暂停视频、关闭窗口、结束本地服务，**不会在后台继续播放**。

调试用：`MSZ_NO_WINDOW=1 python3 msz_bili.py`。

---

## 二、播放链路

1. `/x/web-interface/view` 取 cid，`/x/player/playurl` 取 mp4 整段直链；
2. 浏览器不直连 CDN，改请求本地 `/stream?bvid=...&qn=...`，由本地服务补 `Referer` 与 UA，并**转发 Range 分段**（206，可拖动进度）；
3. 页面用 `<video>` 播放，画质、音量、进度为系统原生控件；
4. 弹幕走 `/danmaku?bvid=...`，拉 `comment.bilibili.com/<cid>.xml`，解压后**全量**下发，前端 canvas 自绘并按轨道排布。

不依赖 B 站网页播放器，也不依赖 mpv / ffplay。

## 三、功能

- **推荐**：热门列表，真实播放量；顶部「换一批」换一组，每次启动的起始页也是随机的
- **搜索**：视频 / 用户 / 专栏三类切换，切换即重新请求
- **详情**：标题、UP 主、播放量、弹幕数、评论数、简介、发布日期
- **播放**：内置播放器；`画质` 下拉按接口返回的可选清晰度切换（切换后自动回到原进度）；`弹幕` 三档（全部 / 少量 / 关闭）；`全屏` 下弹幕正常显示
- **UP 主主页**：站内打开，不跳浏览器。头像、昵称、签名、粉丝数、投稿数、投稿列表（可加载更多）
- **专栏**：站内阅读，正文直接排版显示；想看图可点「在浏览器打开原文」
- **评论**：楼中楼内嵌、翻页；登录后可见完整评论区
- **分区**：全站 + 16 个分区（动画/番剧/国创/音乐/舞蹈/游戏/知识/科技/运动/生活/美食/动物圈/鬼畜/时尚/资讯/娱乐），分区排行榜
- **我的**：头像、昵称、等级、大会员、粉丝/关注/硬币；未登录给出登录引导
- **收藏夹**：读取账号下的收藏夹列表，点开看里面的视频（需登录）
- **观看历史**：云端观看记录，点开续看（需登录）
- **互动**：点赞、投币、关注 UP、发弹幕（需登录，服务端自动带 csrf）
- **动态**：关注动态（视频动态直接内嵌可播；纯文字动态显示文字），需登录
- **番剧**：全部 / 连载 / 完结三档索引，点开看剧集列表，点剧集直接在客户端播放（免费集可播，大会员集按账号权限）
- **直播**：推荐直播间列表，点开即播（服务端改写 m3u8 并中转分片，解决防盗链）
- **投稿（客户端直接投）**：选文件 + 标题/分区/标签/简介 → 走 B 站网页端 upos 上传（预上传→分片→合片→`/x/vu/web/add` 提交），上传过程有日志，成功后返回稿件号
- **投稿（系统浏览器）**：点左侧「投稿」会自动用**系统默认浏览器**打开官方投稿页（用的就是你平时登录的浏览器，登录态直接可用）
- **收藏夹分页**：收藏夹内容支持「加载更多」，不再只显示前 20 条
- **消息**：未读数（回复 / @ / 点赞 / 系统）+ 回复我的列表，需登录
- **下载**：详情页点「下载」把视频存成本地 mp4（`~/Downloads/MSZ-Bili-PC`），下载页可查看已下文件
- **倍速播放**：0.5x / 1.0x / 1.5x / 2.0x
- **全屏**：容器全屏，弹幕在真全屏下照常渲染；左上角有「✕ 退出全屏」按钮（用视频原生全屏按钮时也会自动转到带弹幕的全屏）
- **登录态互通（自动）**：客户端扫码登录 → 自动把 Cookie 推进浏览器（投稿页随之已登录）；只在投稿页登录过 → 客户端任一请求会自动把 Cookie 拉回服务端，点赞/投币/关注/历史/动态/评论/画质全部跟着生效
- **画质自检**：设置页可一键查询当前账号能拿到的清晰度
- **全局返回键**：顶栏左侧「← 返回」，任意页面一键回上一页（离开视频页会自动暂停）
- **稍后再看**：本地保存（`~/.msz-bili-pc/state.json`）
- **扫码登录**：侧栏或设置页点「扫码登录」，用 B 站手机客户端扫一下即可；Cookie 只存在本机 `state.json`，可随时「退出登录」

## 四、三个历史问题

| 问题 | 处理 |
| --- | --- |
| 零播放 / 零关注 | 搜索接口播放量在 `play`、粉丝数在 `fans`；已按字段兜底，实测 173.5 万播放、2096.4 万粉丝 |
| 评论区不全 | 未登录时 B 站只公开 3 条；扫码登录后恢复完整评论区 |
| 防封 | 请求间隔 0.9–1.4 秒抖动、每分钟 30 次上限、412 自动冷却 5 分钟、写操作本地拦截 |

> 补充：B 站空间接口（UP 主页）风控比普通接口更严，偶尔会回 `-352 / -412 / -509`。程序会先重试一次，仍失败时自动退回「按 UP 名搜索并过滤作者」，页面上也有「重试」。

## 五、隐私与免责

- 不登录时完全不携带账号 Cookie；登录后 Cookie 仅存本机，不上传。
- 数据来自 B 站公开接口，仅供个人学习自用，请遵守 B 站用户协议，不得商业分发。
